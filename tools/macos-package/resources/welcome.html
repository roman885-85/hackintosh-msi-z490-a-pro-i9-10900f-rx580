Драйвери для MSI Z490-A PRO (macOS)

Пакет ставиться вже після встановлення macOS на комп'ютер, що завантажується через OpenCore з цього репозиторію (Core i9-10900F, Radeon RX 580, Realtek RTL8125B, Broadcom BCM4360, Realtek ALC897, модель Mac — MacPro7,1). Кнопкою «Налаштувати» можна зняти будь-який пункт.

  • Вбудований звук (VoodooHDA 3.6.8) — на macOS 26 і новіших (Apple прибрала AppleHDA). Після встановлення дозвольте його в «Параметри → Конфіденційність і безпека» і перезапустіть.
  • Wi-Fi Broadcom: патчі OCLP — на macOS 14+ накладає патчі «Modern Wireless» (2–5 хвилин), якщо їх ще немає для цієї збірки macOS. Потрібні встановлений OpenCore Legacy Patcher і драйвери Wi-Fi у EFI (див. README). Якщо OCLP немає — пункт нічого не робить.
  • OpenCore Legacy Patcher і завантажувач OpenCore — лише в пакеті, зібраному з ключами --with-oclp / --with-efi.

Журнал встановлення: /var/log/z490-drivers-install.log.
