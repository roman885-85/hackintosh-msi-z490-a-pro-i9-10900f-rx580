Драйвери для MSI Z490-A PRO (macOS)

Пакет для комп'ютера на MSI Z490-A PRO: Core i9-10900F, Radeon RX 580, Realtek RTL8125B, Broadcom BCM4360, Realtek ALC897, модель Mac — MacPro7,1.

Що він робить (кнопкою «Налаштувати» можна зняти будь-який пункт):

  • Завантажувач OpenCore — ставить робочий OpenCore на розділ EFI системного диска, якщо його там немає. Такий самий не чіпає; інший не замінює, а кладе поруч у EFI_from_pkg.
  • Вбудований звук — на macOS 26 і новіших ставить VoodooHDA (Apple прибрала AppleHDA). Після встановлення дозвольте його в «Параметри → Конфіденційність і безпека» і перезапустіть.
  • OpenCore Legacy Patcher 3.0.0-rc.3 — офіційний пакет Dortania без змін.
  • Wi-Fi Broadcom — на macOS 14+ накладає патчі OCLP «Modern Wireless», якщо їх ще немає для цієї збірки macOS (2–5 хвилин).

Журнал встановлення: /var/log/z490-drivers-install.log.

Перед збиранням пакета впишіть у EFI/OC/config.plist власні серійні номери (GenSMBIOS, MacPro7,1).
